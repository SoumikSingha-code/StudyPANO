# 📚 StudyPANO

### **Learn • Lead • Excel**

StudyPANO is a student-focused study platform designed to make learning, revision, note-making, and exam preparation more organized and effective.

It brings useful study resources and productivity features together in one place, helping students spend less time searching and more time studying.

🌐 **Live Website:** https://study-pano.vercel.app/

---

## ✨ Features

### 📄 Papers

Access and organize previous examination papers and practice material to prepare better for exams.

### 📝 Notes

A dedicated space for notes and revision material, designed to make studying easier and more organized.

### 🧠 Note-Making Guide

StudyPANO includes a detailed guide explaining how to create effective notes, including:

* Understanding concepts before writing
* Using headings and subheadings
* Writing in keywords and bullet points
* Using diagrams and flowcharts
* Subject-wise note-making techniques
* Question-and-answer based notes
* Quick revision sheets
* Cornell Method
* Mind maps
* Formula sheets

The website focuses on keeping notes **short, clear, organized, and easy to revise**.

### 👤 My Profile

Users can manage their profile information, including:

* Name
* Profile photo
* Phone number
* Student/Teacher role

### ⚙️ Settings

StudyPANO provides a settings area with features such as:

* Focus Mode
* Notifications
* Progress Board
* Feedback
* Papers
* Notes
* Privacy Policy
* Terms & Conditions

### 🔔 Notifications

Users can choose whether they want StudyPANO to send notifications.

### 💬 Feedback

A feedback option allows users to share suggestions and help improve the platform.

### 🔐 Login

StudyPANO provides login options including:

* Google Login
* Email ID Login

---

## 🎯 Purpose

StudyPANO was created with a simple goal:

> **Make studying more organized, focused, and easier for students.**

Instead of keeping study resources scattered across different places, StudyPANO aims to provide a centralized platform for learning and exam preparation.
